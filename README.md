The funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation: it hands the on-call pager to the intern model, which has already escalated itself twice and is now billing it in tokens.

## Run it

```sh
node main.ts
```

It writes the entry (134 characters, one line) to `/output/entry.txt`.
